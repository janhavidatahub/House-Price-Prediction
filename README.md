# HousePriceBot — WhatsApp-Based House Price Prediction System

## Description

**HousePriceBot** is an end-to-end academic Machine Learning project that allows users to predict California house prices through a WhatsApp conversational interface.

The user sends a message to the WhatsApp bot, answers eight questions about a house's block group (median income, house age, number of rooms, etc.), and receives an estimated median house value predicted by a trained Random Forest Regressor.

**Why Machine Learning?**
Rule-based systems cannot accurately model the complex, non-linear relationships between housing features and prices. Random Forest captures these relationships by training on thousands of real examples from the California Housing dataset.

**Why WhatsApp?**
WhatsApp is one of the most widely used messaging platforms in the world. Using it as an interface removes the need for a dedicated app or website — any user with WhatsApp can interact with the ML model instantly.

## Architecture

```
WhatsApp User
      ↓  (types a message)
WhatsApp Cloud API  (Meta Graph API)
      ↓  (webhook POST request)
Node.js + Express Backend
      ↓  (HTTP POST /predict)
Python FastAPI ML Service
      ↓  (numpy feature array)
Scikit-learn Random Forest Regressor
      ↓  (predicted value)
Python FastAPI
      ↓  (JSON response)
Node.js + Express
      ↓  (formatted reply)
WhatsApp Cloud API
      ↓
WhatsApp User  ← receives predicted house price
```

## Dataset

**California Housing Dataset** (from `sklearn.datasets.fetch_california_housing`)

This dataset contains information about block groups in California from the 1990 census. Each row represents a block group (a small geographic unit).

### Features (8 inputs)

| Feature | Description |
|---|---|
| `MedInc` | Median income in block group (in $10,000 units) |
| `HouseAge` | Median house age in block group (years) |
| `AveRooms` | Average number of rooms per household |
| `AveBedrms` | Average number of bedrooms per household |
| `Population` | Block group population |
| `AveOccup` | Average number of household members |
| `Latitude` | Block group latitude |
| `Longitude` | Block group longitude |

### Target

| Target | Description |
|---|---|
| `MedHouseVal` | Median house value in $100,000 units (e.g., 4.21 = ~$421,000) |

---

## Machine Learning

### Train-Test Split
The dataset is split 80% for training and 20% for testing (`random_state=42`).

### Model — Random Forest Regressor
Random Forest builds many decision trees on random subsets of the data and averages their predictions. This reduces overfitting and generally achieves high accuracy on tabular datasets.

Configuration:
```python
RandomForestRegressor(n_estimators=200, random_state=42, n_jobs=-1)
```

### Model Saving
The trained model is saved using `joblib` to `artifacts/house_price_model.joblib`. FastAPI loads this file at startup and reuses it for every prediction request without retraining.

### Optional Comparison
`train.py` also trains Linear Regression and Ridge Regression for comparison. All three models' metrics are saved in `metrics.json`. However, only the Random Forest model is used for predictions in the chatbot.

---

## Evaluation Metrics

| Metric | Formula | Meaning |
|---|---|---|
| **MAE** | mean(|actual − predicted|) | Average absolute error |
| **MSE** | mean((actual − predicted)²) | Penalises large errors more |
| **RMSE** | √MSE | Same units as target; easier to interpret |
| **R²** | 1 − SS_res/SS_tot | 1.0 = perfect; 0.0 = baseline mean model |

## Installation & Setup

### Requirements
- Python 3.9+ (recommended: 3.11)
- Node.js 18+
- npm

---

### Step 1 — Set Up Python Environment

```bash
cd HousePriceBot/ml-service
```

Create a virtual environment:
```bash
python -m venv venv
```

Activate the virtual environment:

**Windows:**
```bash
venv\Scripts\activate
```

**Linux / macOS:**
```bash
source venv/bin/activate
```

Install Python dependencies:
```bash
pip install -r requirements.txt
```

---

### Step 2 — Train the Machine Learning Model

```bash
python train.py
```

This will:
- Download the California Housing dataset
- Train Random Forest, Linear Regression, and Ridge Regression
- Print evaluation metrics (MAE, MSE, RMSE, R²)
- Save `artifacts/house_price_model.joblib`
- Save `artifacts/metrics.json`
- Save `artifacts/actual_vs_predicted.png`

You must run this **once** before starting the FastAPI service.

---

### Step 3 — Start the Python FastAPI ML Service

```bash
uvicorn app:app --reload --port 8000
```

Verify it is running:
```
GET http://localhost:8000/health
```

Expected response:
```json
{"status": "ok", "service": "house-price-ml-service", "model_loaded": true}
```

---

### Step 4 — Set Up the Node.js Backend

Open a **new terminal**:

```bash
cd HousePriceBot/backend
```

Copy the environment file:
```bash
# Windows
copy .env.example .env

# Linux / macOS
cp .env.example .env
```

Open `.env` and set at minimum:
```
PORT=3000
ML_SERVICE_URL=http://localhost:8000
```
(WhatsApp credentials are only needed for live WhatsApp mode.)

Install Node.js dependencies:
```bash
npm install
```

Start the server:
```bash
npm start
```

## WhatsApp Cloud API Setup (Live Mode)

### Prerequisites
- Meta Developer account
- WhatsApp Business account
- A public HTTPS URL for your server (use [ngrok](https://ngrok.com) for local development)

### Steps

1. Go to [developers.facebook.com](https://developers.facebook.com)
2. Create a new App → Business type
3. Add the **WhatsApp** product
4. Go to **WhatsApp → API Setup** to get:
   - `WHATSAPP_ACCESS_TOKEN`
   - `WHATSAPP_PHONE_NUMBER_ID`
5. Go to **WhatsApp → Configuration → Webhook**
6. Set Callback URL to: `https://your-domain.com/webhook`
7. Set Verify Token to the same value as `WHATSAPP_VERIFY_TOKEN` in your `.env`
8. Subscribe to the `messages` webhook field
9. Update your `.env` with real credentials

### Expose localhost with ngrok (for testing)
```bash
ngrok http 3000
```
Use the generated `https://xxxx.ngrok.io` URL as your webhook callback URL.

## Important Notes

### In-Memory Conversation State
The current academic prototype uses a JavaScript `Map` for conversation state. Each user's session is stored in memory keyed by their phone number. This means:
- Sessions are lost when the server restarts
- Multiple server instances would not share state

A production system could replace this with persistent storage such as Redis or a database.

### No Database
This project uses no database. No data is persisted between server restarts. This keeps the project simple and appropriate for an academic prototype.

### No LLM / AI Chatbot
The chatbot is entirely rule-based. It follows a fixed question-answer flow. The intelligence in this project comes from the Machine Learning model (Random Forest), not from a language model.

### Target Units
The California Housing dataset target (`MedHouseVal`) is in units of **$100,000**.
- `predicted_price = 4.21` → approximately **$421,000**
- Always multiply by 100,000 for the USD amount

## Academic Explanation (Viva Summary)

> "HousePriceBot is a WhatsApp-based house price prediction system. The user provides California Housing dataset features through a conversational WhatsApp interface. Node.js and Express manage the WhatsApp webhook and maintain conversation state using an in-memory Map. The collected data is sent over HTTP to a Python FastAPI service. The FastAPI service uses a trained Scikit-learn Random Forest Regressor to predict the median house value. The prediction is returned to Node.js, formatted into a readable message, and sent back to the user through WhatsApp. The project evaluates the model using MAE, MSE, RMSE and R² and generates an actual-vs-predicted visualization for the project report."
